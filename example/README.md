# Gulf Currency example

This Flutter example demonstrates `CurrencyText` and the customizable
`CurrencyPicker`. It supports Flutter's web target as well as the other Flutter
platforms. The package's bundled currency symbol fonts are declared through the
package dependency and are included by Flutter when the example is built for
the browser.

To open the web example in Microsoft Edge:

```bash
cd example
flutter run -d edge
```

The `web/` directory contains the browser entry page, app manifest, and favicon.
